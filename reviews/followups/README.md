# Follow-up Research Plans

Generated plans convert unresolved profile or evidence gaps into bounded Discovery
queries for a later Run. They are internal control artifacts, not accepted findings
or publication approvals. A consuming Run snapshots the selected plan and records
its digest before creating Work Items.

Center plans target missing profile fields. Worldwide plans target unmet region,
technology, maturity, result, language, organization, or Source-class coverage.
Duplicate worldwide gaps such as `standards-body` are merged into one query, and
repeated misses advance a recorded search generation instead of replaying the same
search indefinitely.
