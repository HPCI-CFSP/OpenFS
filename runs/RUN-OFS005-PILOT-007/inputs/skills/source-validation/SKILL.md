# Source Validation

Review the assigned proposal before reading other reviewers' conclusions. Check
identity, citation fidelity, scope, units, dates, source class, rights, Origin Group,
claim kind, uncertainty, and whether the conclusion exceeds the Evidence. Re-open
the cited public Source when the assignment allows network access; record an
unverifiable check as uncertain rather than support.

Use `tools/create_assessment.py` with the registry-assigned reviewer identity.
Provide explicit checks and objections, including non-critical concerns. Write only
the declared assessment path. Never self-declare a different independence group,
substitute a proposal, or treat another model's agreement as Evidence.
