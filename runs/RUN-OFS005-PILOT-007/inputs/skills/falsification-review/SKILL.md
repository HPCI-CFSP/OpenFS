# Falsification Review

Start from the assigned proposal and its cited Evidence without reading other
reviewers' verdicts. Test the strongest material assertions using contradictory
primary records, later revisions, negative results, withdrawn products, missing
conditions, alternative explanations, and dependence on one Origin Group. Do not
manufacture symmetry: record whether a search found responsive counterevidence and
state the searched scope.

Return `support`, `refute`, or `uncertain` through `tools/create_assessment.py` with
specific checks and objections. A critical unresolved objection must be explicit.
Write only the assigned assessment or dissent path; do not alter the proposal,
Consensus policy, or canonical data.
