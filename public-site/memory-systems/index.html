メモリ素子から計算システムへ

OpenFSは、将来の計算・データ基盤を検討するための公開情報調査です。メモリ研究の成果を、容量・精度・信頼性・ソフトウェア・供給条件と結び付けて整理します。

単一AIによる暫定整理です。独立検証は未完了であり、採用実績や性能向上を保証するものではありません。

公開根拠で比較する

組込みメモリ、研究素子、演算アーキテクチャを区別します。NAND/HBFは記憶媒体・実装、CXLは接続規格、CIM/PIMは演算配置の方式であり、同じ製品分類ではありません。

アレイ内部のTOPS/Wや素子の省電力率を、アプリ全体の性能・電力へ直接換算しません。OCTRAMはDRAMであり、会議のセッション名だけで不揮発性メモリと分類しません。
