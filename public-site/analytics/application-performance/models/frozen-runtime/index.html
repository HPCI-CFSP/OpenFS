保存済み性能モデル / Frozen runtime models

予測値のリンクに表示するSHA-256は、その予測に保存されたモデルまたは予測固定記録の識別子です。最新モデルへの付け替えや、精度認証を意味しません。 / The linked SHA-256 identifies the model or forecast-freeze record stored with that prediction. It is not silently reassigned to current code and is not an accuracy certification.

カーネル別Roofline・残差保持と通常実行区間 / Sampled Roofline residual and normal phases

保存モデルSHA-256 / Frozen model SHA-256: 0c6b235d14f23bc9712f8296dad78b911e1d279fb8a074b8f9226fb82739e050

通常3反復の中央値をT0（秒）、別トレース区間をW（秒）とし a=T0/W。各カーネルのトレース秒数にaを掛け、通常実行に換算します。 / T0 is the median of three retained normal runs, W is a separate trace window in seconds, and a=T0/W scales kernel trace time to normal execution.

Rj = max(F64 / (P64j × 10^12) + F32 / (P32j × 10^12),
         HBMbytes / (BWj × 10^9))
d = profiled_nanoseconds / 10^9
ratio = (max(0, d − R0) + R1) / d    when R0 ≤ d
ratio = max(1, R1 / R0)              otherwise
t1 = trace_kernel_seconds × a × ratio
C = sum(t1) + non_GPU_trace_seconds × a
Total = C × representative_compute / T0 + initialization + finalization

F64/F32は呼出し当たり標本中央値の演算数、P64/P32はTFLOP/s、HBMbytesは標本の実HBM転送バイト、BWはGB/s（10^9 B/s）。FP64とFP32の計算時間を足し、メモリ転送との重なりはmaxで扱います。カウンタ未取得カーネルは基準値で据え置きます。通常実行合計が中央値となる反復の区間を最終換算に使用します。 / F64/F32 are median sampled per-invocation operation counts; peaks are TFLOP/s, HBMbytes are sampled traffic bytes, and BW is GB/s (10^9 B/s). Arithmetic precisions are serialized; compute overlaps memory via max. Uncaptured kernels remain at baseline. Phase scaling uses the normal row with median total.

通常実測と別プロファイルの区間比を使うため、摂動と移植・ホスト性能は未校正です。カーネルが重なる場合は排他的モデルが必要です。0.5–2倍の固定時間と別効率仮説から感度範囲を示し、信頼区間とは呼びません。 / Trace perturbation, ports and host performance are uncalibrated. Overlapping kernels require an exclusive critical-path model. Sensitivity varies held-constant time by0.5–2× and alternate efficiency assumptions; it is not statistical confidence.

更新区間のみのカーネルモデル / Update-only sampled kernel model

保存モデルSHA-256 / Frozen model SHA-256: 9263a1a91a5469b8c9624a93249644da85be60b052cc15dfbe3657451cf41347

上と同じカーネル別残差式を使いますが、出力は C のみです。初期化・終了処理を推測して加えず、main全体の実行時間とは呼びません。 / Uses the same kernel residual equation above but returns C only. Initialization and finalization are not invented or included; the result is not full-main runtime.

時間比併用 / Profile time-share hypothesis

f = kernel_interval_union_seconds / profile_window_seconds
T = T0 × ((1 − f) + f × B0/B1)

T0は通常実行の更新区間中央値、B0/B1は基準・予測先の公称GB/s、fは別トレースのGPU稼働和集合比です。全カーネルを帯域律速と仮定し、GPU非稼働時間は据え置きます。非稼働時間を純粋なCPU時間とは呼びません。 / T0 is normal update median, B0/B1 are catalog GB/s, and f is a separate trace's GPU-active interval union fraction. All kernels are hypothesized bandwidth-bound; other time remains fixed and is not labeled pure CPU time.

帯域比例 / Bandwidth-only hypothesis

T = T0 × B0/B1

全更新区間を帯域だけで換算する仮説です。時間比モデルとは別です。 / Hypothetically scales the entire update by bandwidth, distinct from the time-share model.

時間比・帯域比例の版リンクは予測固定記録のSHAを示します。 / Version links for time-share and bandwidth-only point to their stored forecast-freeze digest.

各予測を選ぶと、実際の入力値、カーネル標本、算術の中間値、基準機・条件・固定日時を表示します。対象機の観測を用いた再調整は行いません。 / Select a prediction to inspect actual inputs, kernel samples, intermediate arithmetic, baseline conditions and freeze time. Target observations do not refit the calculation.

ソースcommit、入力commit、実行物SHAは異なる来歴です。未確認のリポジトリ・commitは不明として表示します。 / Source commit, input commit and executable SHA are different provenance identifiers. Unverified repositories and commits remain unknown.
