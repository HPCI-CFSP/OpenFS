# Benchmark result proposals

This directory stores provisional `BMR-*.json` result bundles produced by an
assigned `synthesis` Work Item. Each bundle must validate against
`schemas/benchmark-result-bundle.schema.json` and pass
`tools/check_benchmark_result_bundle.py` before independent review.

Bundles are proposals, not canonical findings. Keep raw measurements at the
declared immutable URI and record its SHA-256 digest; do not commit restricted,
personal, or NDA data here. Promotion requires independent reproduction,
Consensus, and any applicable human decision.
