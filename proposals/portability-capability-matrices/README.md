# Portability capability matrix proposals

Place candidate matrices for `GAP-PORT-001` here. Use
`schemas/portability-capability-matrix.schema.json`, retain test artifacts in a
public durable repository, and validate with
`tools/check_portability_capability_matrix.py` before independent review.

Do not commit credentials, private build paths, NDA material, or a matrix that
silently omits an unsupported compiler-feature pair.
