# OpenFS Public Research

OpenFS continuously organizes public evidence about computing architectures,
system software, applications, operations, procurement, and policy to support
future system planning. The published site presents provisional status,
Coverage Gaps, and Consensus information alongside findings and roadmaps.

This repository is the **public distribution surface**. It contains only
reviewed public data, evidence, reports, accepted scenario data, and a generated
static site. Research automation, generators, tests, internal reviews, and run
records are maintained outside this public repository.

## Contents

| Path | Purpose |
| --- | --- |
| `public-site/` | Generated static site deployed to GitHub Pages |
| `knowledge/public/` | Public structured findings, evidence indexes, and audits |
| `roadmaps/scenarios/accepted/` | Approved public scenario data |
| `reports/exports/` | Public report exports |
| `assets/branding/` | OpenFS public brand assets |
| `PUBLICATION_MANIFEST.json` | Source revisions, validation status, and hashes for the publication bundle |

See [PUBLICATION.md](PUBLICATION.md) for the publication boundary, verification,
and update procedure. Corrections and research requests can be submitted through
[Feedback](https://hpci-cfsp.github.io/OpenFS/feedback/?lang=en).
