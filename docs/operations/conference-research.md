# Conference-driven public research

## Scope and evidence

Start from the official program, not the subset that is easy to retrieve.
`knowledge/public/conferences/HC2026.json` inventories 48 Hot Chips 2026 entries:
26 technical talks, 10 tutorials, one keynote and 11 posters. Presenter affiliations,
coauthors, development partners and sponsors are different roles. Sponsor coverage
is unresolved in this snapshot. Company names are not evidence of country of origin.

Research conference technologies and their direct dependencies, not every product
from every company. Secondary reports are discovery leads. FMS announcements,
earlier product disclosures and earnings commentary are related context, not new
Hot Chips disclosures. The preview's Mojo Vision entry and the checked program
disagree; preserve that discrepancy without claiming cancellation.

## Reproducible update

1. Read the current program, record all entries and compare additions/removals.
   A count alone is insufficient: preserve stable entry IDs and affiliation roles.
2. Search the conference, issuer and project sources. Record exact URLs and
   retrieval scope. A program title or an abstract cannot stand in for a full paper.
   A failed retrieval is not proof that no public information exists. Never bypass
   paywalls, attendee-only access or shell-network restrictions.
3. Use the bounded provisional-update workflow to append catalog explanations.
   The catalog is the sole technical-text source. Conference entries reference
   its item IDs; the page renders those records without copying their text.
4. Link announcement, sampling, production, internal deployment, cloud availability
   and external sales separately. Keep original timing precision: a year-end
   deadline is not a Q4 start; "early 2027" does not prove Q1. Existing comparable
   milestones remain; append a new event only when its semantics differ.
5. Update the source-to-catalog map and roadmap assurance projections. Run schema,
   semantic, bilingual, link, privacy and regression checks. Publish by review PR.
   A future automated proposal still requires the normal Consensus Gate; this
   interactive human-authorized update does not grant an automation exception.

`tools/check_conference_coverage.py` checks the 48-entry denominator, active-topic
ownership, referenced claims, source retrieval scope and provisional status.
`WATCH-HOTCHIPS-2026` adds a discovery target to the existing monitor; it does not
start a scheduler. The official FAQ targets public proceedings for early December
2026. Until then, retain program-only/abstract-only/related-primary distinctions.

The 2026-08-31 scan used the supplied reports, the full public program, and managed
Web searches for Hot Chips 2026, each technical presenter/product, the RISC-V and
memory tutorials, and named posters. Exact successful URLs and read scope are in
the register and RUP source checks. This is a bounded scan, not exhaustive proof
of absence; future agents should repeat searches for entries with open gaps.

## 日本語

発表・共著組織、開発協力組織、スポンサーを区別し、企業名だけで地域分類しません。
調査対象は会議の技術と直接の関連技術であり、各社の全事業・全製品ではありません。
二次記事は調査の手掛かりとし、FMSや過去の発表を会議での新規発表と混同しません。
Mojo Visionの事前記事と公式日程の相違は、理由が判明するまで未確認事項として残します。

発表一覧と技術内容の検証は別です。要旨だけの確認を全文確認と扱わず、取得失敗を
公開情報が存在しない根拠にしません。認証・課金制限やShellの通信制限を回避しません。
技術解説の正本はカタログに置き、会議ページではそのIDを参照して同じ記述を表示します。
日程は発表、試作、量産、社内導入、クラウド提供、一般販売を区別し、年だけの情報から
四半期を推測しません。新しい調査結果も暫定・Consensus未完了のまま維持します。

情報源とカタログの対応表、ロードマップ監査の派生データも更新して検証します。
監視対象の追加は自動実行の開始を意味せず、将来の自動提案にも通常のConsensus Gateが
必要です。講演資料の一般公開予定は2026年12月初旬です。公開後に未確認項目を照合します。
今回の検索は指定記事、公式日程、登壇組織・製品、チュートリアルと各ポスターを起点とした
範囲限定の調査です。確認できたURLと確認範囲を台帳・更新記録へ残し、未確認項目は再検索します。
