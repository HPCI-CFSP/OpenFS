# OFS-004: AI提案による新規調査項目の継続発見

## 目的

過去FS由来のカタログを残しつつ、既存Topicでは十分に説明できない技術、利用形態、制度、リスクをAIエージェントが毎週探索し、追加Topicとして提案する。

## 提案要件

- 現行の全Topic IDとの差分を示す。
- 原則として2つ以上のSource Origin Groupを示す。
- 新規性だけでなくHPCI整備判断への影響、必要な証拠、期待出力、監視頻度を示す。
- 反証検索と「既存Topicへの統合で足りる」という代替仮説を含める。
- 別の独立エージェントが新規性、重要性、重複、誇張をレビューする。

## 出力と採用

Discoveryは日英Topic名を含む候補を`proposals/research-topics/`へ置く。検証・反証・`research_topic` Consensus Gateで`accepted`となった追加専用Proposalだけを、`topic-promotion` RoleがBaseline、`config/publication-i18n.json`、`MON-AUTO-TOPICS-001`へ同時登録する。次回Runでは登録済みQuery Planから他のDiscovery Agent向けWork Itemを生成する。

初期30 Topicおよび既存Topicの削除、縮小、置換、統合、分割、廃止はこの自動経路から実行できず、人のDirectiveを必要とする。詳細は`docs/research-baseline/ai-topic-promotion.md`に従う。

## 完了条件

継続型Taskであり、各週に「候補あり」または検索範囲と根拠を伴う「有意な候補なし」を記録する。
