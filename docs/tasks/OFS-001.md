# OFS-001: 2030年代HPCI向けメモリ階層候補の継続調査

## 目的

HPCおよびAI for Scienceのアプリケーション特性を踏まえ、2030年代のHPCIで検討すべきメモリ階層、接続方式、運用方式の候補を継続的に調査する。

## 主な問い

- 帯域律速、遅延律速、容量律速などの特性空間に対し、どのメモリアーキテクチャが有効か。
- HBM、DDR系、CXLメモリ、メモリプーリング、不揮発性メモリなどの成熟度と導入時期はどう変化しているか。
- 実効性能、費用、電力、プログラマビリティ、運用性、調達リスクをどう比較するか。
- メモリアクセスパターンを、離散的な名称ではなく性能特性に基づく連続空間として扱えるか。

## 出力

- 情報源（Source）、根拠（Evidence）、主張（Claim）、知見（Finding）の候補。
- 技術成熟度と導入時期の差分。
- 複数のメモリ階層シナリオ。
- ロードマップ項目の候補と、判断に必要な未確認事項。
- 週次ダイジェストのメモリ分野。

## 完了条件

この調査タスク自体は継続型であり、完了扱いにはしない。調査モニターの対象範囲、網羅状況、未解決の例外、最終確認日時を実行のたびに更新する。

最初のハーネス検証では、初回収集、情報源の更新に伴う差分処理、人が発行した指示（Directive）の反映という3回の手動実行を成功させる。
