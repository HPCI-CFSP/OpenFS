# OFS-005: 世界のHPCI関連技術動向の広域・継続調査

## 目的

世界各地で研究、開発、製造、標準化、実証、運用されるHPCI関連技術を、現在判明している国・企業・製品・研究テーマに限定せず継続的に発見し、HPCI整備計画への適合性を評価する。その中で、日本発技術は見落としを防ぐため優先的かつ広範に調査する。

## 調査範囲

機械可読な正本は`config/global-technology-scope.json`とする。対象地域は全世界であり、半導体・材料・製造・実装、計算・メモリ・ネットワーク・ストレージ、システムソフトウェア・セキュリティ、量子、アプリケーション、電力・冷却・施設、スタートアップ・OSS・標準化・人材・供給網までを含む。

特定の地域・組織・技術に限定しない。英語圏だけでなく各地域の一次情報を可能な範囲で原言語でも確認し、日本については日本語・英語の両方で優先的に検索する。新しい分類が必要な場合は`OFS-004`のResearch Topic ProposalとしてConsensus Gateへ送る。

## 必須処理

1. 世界各地の政府・研究機関・大学・企業・スタートアップ・標準化団体・OSSの一次情報を検索する。
2. 日本発技術については日本語・英語の両方で優先検索し、国際的な代替候補と同じ評価軸で比較する。
3. 論文・発表だけでなく、実証、量産、調達、導入、保守、停止・撤退、失敗結果も記録する。
4. HPCIでの価値、性能・電力、成熟度、ソフトウェア、量産・供給、運用、相互運用、費用・時期、人材・産業波及、代替策を評価する。
5. 開発地域だけを採用根拠とせず、国際比較、併用案、fallback、段階導入Gateを示す。
6. 毎週、未探索の地域・カテゴリ・情報源クラス、取得失敗、前回からの変化をCoverageとして残す。

## 出力

- 世界技術動向レーダーとSource/Evidence Proposal。
- 日本発技術の優先調査Coverageと国際比較。
- 技術カテゴリ別の成熟度・HPCI適合性表。
- 実証、共同開発、調達、継続、撤退の判断Gate。
- 新しい調査Topicが必要な場合のConsensus対象Proposal。

## 完了条件

継続型Taskである。初期マイルストーンは主要地域、全カテゴリ、全Source Classを少なくとも一度検索し、日本発技術の優先Coverageを含むGapを明示した3回の手動Runを完了することとする。
