# OFS-005: 日本国内のHPCI関連技術の広域・継続調査

## 目的

日本国内で研究、開発、製造、標準化、実証、運用されるHPCI関連技術を、現在判明している企業・製品・研究テーマに限定せず継続的に発見し、HPCI整備計画への適合性を評価する。

## 調査範囲

機械可読な正本は`config/domestic-technology-scope.json`とする。半導体・材料・製造・実装、計算・メモリ・ネットワーク・ストレージ、システムソフトウェア・セキュリティ、量子、アプリケーション、電力・冷却・施設、スタートアップ・OSS・標準化・人材・供給網までを含む。

列挙された組織・技術は検索の起点であり、閉じた候補リストではない。新しい分類が必要な場合は`OFS-004`のResearch Topic ProposalとしてConsensus Gateへ送る。

## 必須処理

1. 国・研究機関・大学・企業・スタートアップ・標準化団体・OSSの一次情報を日本語と英語で検索する。
2. 論文・発表だけでなく、実証、量産、調達、導入、保守、停止・撤退、失敗結果も記録する。
3. HPCIでの価値、性能・電力、成熟度、ソフトウェア、量産・供給、運用、相互運用、費用・時期、人材・産業波及、代替策を評価する。
4. 国内技術であること自体を採用根拠とせず、国際技術との併用案、fallback、段階導入Gateを示す。
5. 毎週、未探索カテゴリ、情報源クラス、取得失敗、前回からの変化をCoverageとして残す。

## 出力

- 国内技術レーダーとSource/Evidence Proposal。
- 技術カテゴリ別の成熟度・HPCI適合性表。
- 実証、共同開発、調達、継続、撤退の判断Gate。
- 新しい調査Topicが必要な場合のConsensus対象Proposal。

## 完了条件

継続型Taskである。初期マイルストーンは全カテゴリと全Source Classを少なくとも一度検索し、Coverage Gapを明示した3回の手動Runを完了することとする。
