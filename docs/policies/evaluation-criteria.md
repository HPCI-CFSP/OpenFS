# HPCI Evaluation Criteria

Status: initial draft; authoritative weights and owners are not yet approved.

Roadmap Recommendations should be evaluated across:

- scientific and societal value;
- target application coverage;
- measured and projected performance;
- capacity, bandwidth, latency, and data-movement characteristics;
- capital and operating cost;
- power, cooling, and facility impact;
- technology and manufacturing maturity;
- procurement and deployment timing;
- software, programming-model, and migration readiness;
- reliability, resilience, security, and operability;
- supply-chain, vendor concentration, and geopolitical risk;
- interoperability with the wider HPCI ecosystem;
- reversibility and option value under uncertainty.

Each score records evidence, assumptions, uncertainty range, evaluator, method version, and sensitivity to scenario weights. Missing evidence remains `unknown`; it does not receive a neutral score automatically.
